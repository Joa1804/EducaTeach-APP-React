# EducaTeach APP React

Aplicação mobile desenvolvida em **React Native** com **Expo**, criada como parte do Projeto Integrador. O objetivo do EducaTeach é oferecer uma plataforma voltada para o ambiente educacional, reunindo recursos que auxiliem na interação entre usuários e no acesso a conteúdos e funcionalidades relacionadas à educação.

## 📱 Sobre o projeto

O **EducaTeach APP React** é a versão mobile do projeto EducaTeach, desenvolvida utilizando tecnologias modernas para aplicações multiplataforma.

O projeto utiliza **React Native** e **Expo**, permitindo o desenvolvimento de uma aplicação que pode ser executada em diferentes plataformas a partir de uma mesma base de código.

A aplicação está sendo desenvolvida de forma incremental, com novas funcionalidades e melhorias sendo adicionadas conforme o andamento do Projeto Integrador.

## 🚀 Tecnologias utilizadas

* **React Native** — desenvolvimento da aplicação mobile
* **Expo** — ambiente e ferramentas para desenvolvimento React Native
* **TypeScript** — tipagem e segurança no desenvolvimento
* **Expo Router** — gerenciamento de navegação e rotas
* **JavaScript/TypeScript** — lógica da aplicação
* **ESLint** — padronização e análise do código

## ⚙️ Pré-requisitos

Antes de executar o projeto, certifique-se de possuir instalado:

* [Node.js](https://nodejs.org/)
* npm
* Expo
* Git

Também é recomendado possuir um dispositivo Android/iOS ou um emulador configurado para testar a aplicação.

## 🔧 Instalação

Clone o repositório:

```bash
git clone https://github.com/Joa1804/EducaTeach-APP-React.git
```

Entre no diretório:

```bash
cd EducaTeach-APP-React
```

Instale as dependências:

```bash
npm install
```

## ▶️ Executando o projeto

Para iniciar o servidor de desenvolvimento do Expo:

```bash
npx expo start
```

Após iniciar, será possível executar a aplicação utilizando um dispositivo físico ou um emulador compatível.
